Лекция 0 — Установка и первый PASS

Цель: увидеть ✓ PASS на сценарии, который я уже написал.

Нужно: Node.js 18+, терминал, минут пятнадцать.

npm install -g @natl/cli @natl/adapter-playwright
npx playwright install chromium
natl --version

Клонируйте репозиторий и прогоните login-фикстуру (локальный HTML — без чужого сайта):

git clone https://github.com/arslan-ahmetjanov/natl.git
cd natl/examples
natl run login.yaml

Ощущение от PASS? Держите его. Весь курс — это то же самое, только глубже.

Попробуйте: сломайте текст assert нарочно, запустите снова, прочитайте FAIL (файл + шаг). Почините. Учёба начинается, когда ломаете безопасно.

Лекция 1 — Анатомия сценария

Откройте examples/login.yaml вместе со мной:

name: Login smoke
engine: playwright
tags: [smoke]
vars:
  base_url: ./fixtures/shop.html
  user: demo@test.com
  pass: secret
steps:
  - goto: $base_url
  - fill: "#email"
    with: $user
  - fill: "#password"
    with: $pass
  - click: "#login-btn"
  - assert: ".welcome"
    text: "Добро пожаловать"

Сверху вниз:

  • name — имя в отчёте
  • engine — как водим браузер (playwright по умолчанию; ещё selenium, cypress, http)
  • tags — метки для --tags
  • vars — значения как $user
  • steps — сценарий

Скоро встретите: timeout, retries, secrets, imports, cases, before_each / after_each, elements, actions, locator_strategy, data. Полный список → Синтаксис.

Свой проект, когда фикстуры надоели:

mkdir my-tests && cd my-tests
natl init
natl run tests/

Лекция 2 — UI-шаги и assert

Глаголы так, чтобы smoke умещался на один экран. Ритм: цель + проверка.

- goto: $base_url
- fill: "#email"
  with: $user
- select: "#country"
  with: "KZ"
- check: "#agree"
- click: "#submit"          # tap: — тот же шаг
- assert: ".ok"
  text: "Done"
- assert: ".ok"
  contains: "Do"
- assert: ".banner"
  visible: true
- assert: ".banner"
  attr: class contains "active"
- assert: current_url contains "/dashboard"

Auto-wait: действия и assert ждут цель в пределах timeout. Обычно не нужен wait: ".ok visible" перед assert.

Явный wait: — для задержки (wait: 500), hidden / attached / detached.

Мягкие ошибки (собрать, не останавливать):

- assert: ".price"
  text: "$10"
  soft: true
- soft_assert: ".stock"
  visible: true

Извлечь значение / лог / скрин:

- get_text: ".title"
  save: page_title
- get_attr: "#link"
  attr: href
  save: href
- screenshot:
    file: artifacts/after-login.png
    full_page: true
- set: $total = $price * $qty
- log: "total=$total"

Жесты (один сценарий для desktop и mobile web — без if: mobile):

- scroll: "#footer"
  into_view: true
- swipe: "#carousel"
  direction: left
- long_press: "#card"
  duration_ms: 700

Попробуйте: examples/soft_assert_demo.yaml и examples/gestures_demo.yaml.

Лекция 3 — Vars, secrets, конфиг проекта

$name — из vars (и из cases / include / do). Вложенность: $order.id.

secrets:
  env:
    file: .env

vars:
  user: $env.TEST_USER
  pass: $secret.TEST_PASS

$env.KEY и $secret.KEY — один store; секреты маскируются в логах. Пример: examples/env_login.yaml.

engine: playwright
browser: chromium
timeout: 15000
base_url: https://staging.example.com
headless: true
artifacts_dir: artifacts
retries: 0
trace: on-fail
video: off
natl run tests/ --env staging
natl run tests/ --config config/prod.yaml

Приоритет слияния: CLI → YAML теста → env-профиль → natl.config → defaults.

Лекция 4 — Page objects (do:)

# pages/login.yaml
elements:
  email: "#email"
  password: "#password"
  submit: "#login-btn"
actions:
  login:
    - fill: $email
      with: $user
    - fill: $password
      with: $pass
    - click: $submit

# pom_login.yaml
imports:
  - pages/login.yaml
steps:
  - goto: $base_url
  - do: login.login
    user: $user
    pass: $pass

do: page.action — основной путь. include: login/login — ниже уровнем. Соседние ключи у do: попадают в scope экшена.

Стратегия локатора — на config / page / element, не на каждом шаге. Сейчас: css, xpath.

Попробуйте: natl run pom_login.yaml из examples/.

Лекция 5 — Data-driven cases:

name: Data-driven login
cases:
  - { name: user1, user: "a@test.com", pass: secret, expect: "Welcome, A" }
  - { name: user2, user: "b@test.com", pass: secret, expect: "Welcome, B" }
steps:
  - goto: $base_url
  - fill: "#email"
    with: $user
  - fill: "#password"
    with: $pass
  - click: "#login-btn"
  - assert: ".welcome"
    text: $expect

В отчёте: … [user1]. На строке — name или label; иначе [case N].

Для вложенных циклов — data: + for:. Для простых таблиц предпочитаю cases:.

Попробуйте: natl run data_driven.yaml.

Лекция 6 — HTTP и with: http

engine: http
vars:
  base_url: http://127.0.0.1:8765
steps:
  - get: $base_url/get
    save: ping
  - post: $base_url/post
    body: { hello: world }
    headers: { X-Test: "1" }
    save: echo
  - assert: $echo.status == 200

Глаголы: get / post / put / patch / delete. Сохраняется { status, headers, body, ok }. Старый api: ещё работает.

engine: playwright
steps:
  - goto: $base_url
  - with: http
    steps:
      - get: $api_base/get
        save: ping
      - assert: $ping.status == 200

Лекция 7 — Поток: if / for / repeat / parallel

- if: $role == "admin"
  then:
    - click: "#admin"
  else:
    - click: "#user"

- for: $item in $data
  steps:
    - log: $item.name

- for: $i in range(1, 3)
  steps:
    - log: "i=$i"

- repeat: 3
  steps:
    - click: "#next"

- repeat:
    until: $done == true
  steps:
    - click: "#poll"

- parallel:
    - get: $api/a
      save: a
    - get: $api/b
      save: b

before_each / after_each — вокруг steps на каждую попытку.

Операторы и builtins — в Синтаксис → Expressions.

Лекция 8 — Tags, retries, фильтры CLI

name: Checkout
tags: [smoke, checkout]
retries: 1
natl run tests/ --tags smoke
natl run tests/ --grep "Login"
natl run tests/ --retries 2
natl run suite.yaml --engine selenium
natl run suite.yaml --headed

--tags — OR; с --grep — AND. Ноль совпадений → exit 1. Retries — весь сценарий заново, свежий контекст.

Задание

  2. natl init в новой папке. Три шага smoke на свою страницу.
  3. Вынести селекторы в pages/, вызвать через do:.
  4. Добавить with: http (echo-stub, если нужно).
  5. Тег smoke и прогон --tags smoke.
