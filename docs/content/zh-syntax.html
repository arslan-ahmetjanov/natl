根字段（场景 YAML）

FieldMeaning
name显示名称（报告、--grep）
tags供 --tags 使用的字符串列表
engineplaywright | selenium | cypress | http
timeout默认步骤超时（毫秒）
retries失败后额外完整场景尝试次数
vars场景变量（$name）
secrets如何加载密钥（见下文）
imports页面 / 共享 YAML 路径
elementsPOM 定位器
actionsPOM 命名步骤列表
locator_strategy字符串选择器的默认值（css | xpath）
cases数据驱动行
data暴露为 $data 供 for: 使用的数组
before_each / after_each每次尝试围绕 steps 的钩子
steps主步骤列表

每个步骤还可携带：timeout、save、debug。要在场景中途切换引擎，用 with: 块——运行时认的是这个。

项目配置与环境 profile

natl.config.yaml（从测试文件向上查找最近的一个）：

engine: playwright
browser: chromium          # adapter-specific
timeout: 15000
base_url: https://staging.example.com
headless: true
viewport: { width: 1280, height: 720 }
locator_strategy: css
artifacts_dir: artifacts
retries: 0
trace: on-fail             # off | on | on-fail
video: off
soft_assert_screenshot: false

环境 profile：config/<name>.yaml，通过 --env staging；或任意覆盖文件 --config path.yaml（二者互斥）。

合并优先级：CLI → 测试 YAML → 环境 profile → 基础 config → 默认值。

UI 步骤

VerbForm
gotogoto: $url 或 goto: { url, timeout } — http(s)、file:// 或相对路径 → 文件
click / tap同一步骤；优先 click:
fillfill: "#id" + 同级 with:
select定位器 + with:（选项值）
check / uncheck定位器
wait毫秒，或选择器 + visible|hidden|attached|detached

自动等待：操作和断言在超时内等待目标。优先用断言，而不是多余的 wait: … visible。

断言

- assert: ".welcome"
  text: "Hello"            # or is:
- assert: ".welcome"
  contains: "Hell"
- assert: $welcome
  visible: true
- assert: ".banner"
  hidden: true
- assert: ".price"
  attr: class contains "sale"
- assert: current_url == "https://example.com/app"
- assert: current_url contains "/app"
- assert: $ping.status == 200
- assert: ".price"
  text: "$10"
  soft: true
- soft_assert: ".stock"    # alias → soft: true
  visible: true

属性运算符内联：==、!=、contains、matches。

软断言收集失败；运行结束时才失败。硬断言是 fail-fast。

提取、赋值、日志、截图

- get_text: ".title"
  save: title
- get_attr: "a"
  attr: href
  save: href
- set: $total = $price * $qty
- log: "hello"
- log: { message: "x", level: warn }   # info|debug|warn|error
- debug: true
- screenshot:
    file: artifacts/shot.png
    full_page: true

手势

- scroll: "#footer"
  into_view: true          # or delta_x / delta_y
- swipe: "#carousel"
  direction: left          # left|right|up|down
  distance: 200
- long_press: "#card"
  duration_ms: 700

桌面与移动 Web 用相同步骤。触摸保真度取决于 adapter 能力。

HTTP

engine: http
steps:
  - get: $base_url/health
    save: ping
  - post: $base_url/login
    headers: { Authorization: "Bearer $token" }
    body: { user: $user }
    save: resp
  - put: …
  - patch: …
  - delete: …
  - assert: $resp.status == 200

保存结构：{ status, headers, body, ok }。相对 URL 在 vars.base_url 为 http(s) 时相对它解析。

与 UI 混用：

- with: http
  steps:
    - get: $api/orders/$id
      save: order

旧版 api: 仍可解析；新代码应使用上述动词。

POM

# pages/login.yaml
locator_strategy: css
elements:
  email: "#email"
  title:
    strategy: xpath
    value: "//h1"
actions:
  login:
    - fill: $email
      with: $user
    - click: "#login-btn"

# scenario
imports:
  - pages/login.yaml
steps:
  - do: login.login
    user: $user
    pass: $pass
  - include: login/login   # path-style / whole-file
    vars: { user: $user }

页面文件可以没有 steps（只有 elements + actions）。natl run tests/ 会跳过 pages/ 和 config/ 目录。

元素的策略优先级：对象 strategy → 页面 locator_strategy → 项目 → css。

Cases 与 data

cases:
  - { name: a, user: a@test.com, expect: "A" }
  - { label: b, user: b@test.com, expect: "B" }
steps:
  - fill: "#email"
    with: $user
  - assert: ".hi"
    text: $expect

data:
  - { name: one }
  - { name: two }
steps:
  - for: $item in $data
    steps:
      - log: $item.name

简单表格优先 cases:；嵌套 / 计算循环用 data: + for:。

流程

- if: $role == "admin"
  then:
    - click: "#admin"
  else:
    - click: "#user"

- for: $i in range(1, 5)
  steps:
    - log: $i

- repeat: 3                 # or "3 times" / times: 3
  steps:
    - click: "#next"        # sets $i

- repeat:
    until: $done == true
  steps:
    - click: "#poll"        # max 1000 iterations

- parallel:                 # wait: all (default) | any
  - get: $api/a
    save: a
  - get: $api/b
    save: b

- parallel:
    wait: any
    steps:
      - get: $api/fast
      - get: $api/slow

变量、密钥与表达式

SyntaxMeaning
$user变量
$order.id嵌套字段
$env.KEY环境 / .env（缺失 → 错误）
$secret.KEY同一存储；日志中掩码
${ENV:KEY}旧版兼容
 
secrets:
  env:
    file: .env
    encoding: utf-8

运算符：== != > < >= <= contains matches and or not。

内置函数：now、today、random_int、random_string、random_uuid、random_email、len、contains、trim、upper、lower、replace、match、join、map、filter、range。

运行时注入 current_url，供 URL 断言 / 表达式使用。

CLI 过滤

natl run tests/ --tags smoke,auth    # OR
natl run tests/ --grep "Login"       # RegExp on name or path
natl run tests/ --retries 2
natl run tests/ --env staging
natl run tests/ --headed
natl run tests/ --engine selenium
natl run tests/ --trace on-fail
natl run tests/ --video off

--tags 与 --grep 用 AND 组合。零匹配 → 退出码 1。

紧凑写法与语法糖

主要写法（应提交到仓库的——合法 YAML）：

- fill: "#email"
  with: $user
- wait: ".dashboard visible"
- assert: ".welcome"
  text: "Hello"

运行时语法糖（预处理器；IDE 可能标为无效 YAML）：

- fill: "#email" with: $user
- assert: ".welcome" text: "Hello"
- scroll: $footer into_view

嵌套对象（fill: { locator, with } 等）对工具链合法。

IDE：通过 YAML 扩展的 yaml.schemas 接入 @natl/core schema——见 CLI README。
